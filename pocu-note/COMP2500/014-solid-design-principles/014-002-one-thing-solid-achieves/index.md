# SOLID로 이룰 수 있는 것 한 가지

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-1.png)

SOLID 정신에서 얻을 수 있는 것은 유연함
- 추상화, 일반화
- [[pocu-note/COMP2500/011-interface-vs-implementation/011-006-where-decoupling-fits/index|디커플링이 적합한 곳들]] 참고

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-2.png)

유연함과 이해하기 쉬움은 독립적이다.

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-3.png)

유지보수 또한 유연함과 독립적이다.

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-4.png)

대규모 프로젝트는 디커플링이 중요하기 때문에 SOLID 정신이 유효하다.

모든 프로젝트는 대규모 프로젝트가 아님

[[pocu-note/COMP2500/011-interface-vs-implementation/011-007-decoupling-disadvantages-1/index#^not-intuitive|추상화는 직관적이지 못함 (구체적인 게 이해하기 쉬움)]] 참고

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-5.png)

시작은 작게 서비스가 커지면 디커플링

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-6.png)

모든 걸 외주로 개발하는 시절에는 유연함이 중요했음

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-7.png)
![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-8.png)
![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-9.png)

요구사항이 잘 안 바뀌고, 설계에 시간을 많이 쓸 수 있음

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-10.png)
![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-11.png)
![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-12.png)
![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-13.png)

요구사항이 자주 바뀌기 때문에 새로 만드는 것이 더 빠를 수 있음

![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-14.png)
![](pocu-note/COMP2500/014-solid-design-principles/014-002-one-thing-solid-achieves/images/one-thing-solid-achieves-15.png)

SOLID 원칙이 마케팅적 요소가 포함되었음을 알 수 있다.
