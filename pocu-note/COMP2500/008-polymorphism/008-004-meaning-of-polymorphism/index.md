# 다형성의 의미 풀이

![](pocu-note/COMP2500/008-polymorphism/008-004-meaning-of-polymorphism/images/meaning-of-polymorphism-1.png)

- 원칙은 ==실제 개체 자료형==의 함수가 호출
    - 변수명은 ==무늬==
    - 실제 개체 자료형은 ==실체==

![](pocu-note/COMP2500/008-polymorphism/008-004-meaning-of-polymorphism/images/meaning-of-polymorphism-2.png)

부모 클래스형의 변수는 다양한 자식 클래스 실제 개체를 참조할 수 있음
- 상속 때문에 가능함
