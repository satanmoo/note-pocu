# 상속, 부모/자식 클래스 소개

## 상속(inheritance)이란?

부모 클래스의 멤버(변수·메서드)를 자식 클래스가 물려받는 것

- Java에서는 `extends` 키워드로 표현

## 부모 클래스를 부르는 다른 용어는?

상위 클래스, super class, base class(기반 클래스)

## 자식 클래스를 부르는 다른 용어는?

하위 클래스, sub class, derived class(파생 클래스)

## 상속 관계는 무슨 관계라고 부르는가?

is-a 관계

- 자식 is-a 부모 (예: Dog is-a Animal)
- 멤버로 가지는 has-a(컴포지션) 관계와 대비됨
