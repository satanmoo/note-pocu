# 패키지

## 패키지 문법

```java
package com.samsung.boom;
```

- `.java` 파일 최상단에 명시, 컴파일 타임에 강제

## 패키지가 academy.pocu.comp2500 이라면 이 클래스가 위치한 폴더는?

src/academy/pocu/comp2500 안으로 강제된다

- 모든 `.java` 소스는 `src` 하위에 위치하고, 패키지명과 폴더 구조가 동일해야 함

## 패키지는 크게 2가지로 나눌 수 있다. 무엇인가?

built-in 패키지

- 패키지의 첫번째가 java로 시작함
- java.lang

user-defined 패키지

## 패키지를 사용하는 목적은?

네임스페이스
