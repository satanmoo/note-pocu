# 상속 vs 컴포지션: 일반적인 경우

## 실제 세계 개념을 어떤 기준으로 상속/컴포지션으로 모델링하는가?

- is-a 관계 (A가 B 중의 하나) → 상속
- has-a 관계 / 독립적으로 존재 → 컴포지션

## 다음 설명 중 틀린 것은?

1. A가 B 중의 하나이면 is-a 관계이고 상속으로 모델링한다
2. A와 B가 독립적으로 존재하면 컴포지션으로 모델링한다
3. 다형성이 필요하면 상속을 사용한다
4. 컴포지션이 상속보다 성능에 유리하다

4번 (틀림)

- 성능은 **상속**이 유리함 (메모리가 연속된 한 덩어리라 캐시에 유리)
- 1, 2, 3번은 모두 옳음
