# Java의 실행 모델

## Java의 컴파일 모델은?

바이트코드 생성

JVM에서 실행 됨

- 네이티브 실행 파일이 아니라 바이트 코드로 컴파일됨

## C의 전통적 컴파일 방식에서 실행 파일은 크로스 플랫폼인가?

NO

- 실행 파일은 특정 플랫폼(OS)에 종속됨
- C에서 크로스 플랫폼인 것은 **소스 코드**뿐

## JVM의 역할은?

- 플랫폼(OS)별로 각각 설치됨
- 바이트 코드를 해당 플랫폼에 적합한 명령어로 바꿔서 실행
- 실행 방식은 플랫폼·구현체·버전에 따라 다양

## Java의 플랫폼은 무엇인가?

JVM
