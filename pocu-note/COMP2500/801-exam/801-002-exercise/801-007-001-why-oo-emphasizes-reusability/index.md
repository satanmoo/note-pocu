# OO에서 재사용성을 중요시하는 이유

## "바퀴를 재발명한다(reinventing the wheel)"는 무슨 의미인가?

이미 존재하는(잘 만들어진) 것을 불필요하게 처음부터 다시 만드는 것

- 시간·노력의 낭비
- 재사용성을 높이면 이를 피할 수 있음

## OO에서 재사용성을 중요시하는 이유는?

- 개발 시간 절약: 이미 만들어진 코드를 다시 활용
- 신뢰성: 이미 검증·테스트된 코드라 버그가 적음
- 유지보수 용이: 코드 중복이 줄어 한 곳만 고치면 됨
