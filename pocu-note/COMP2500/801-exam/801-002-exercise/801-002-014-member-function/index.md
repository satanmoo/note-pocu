# 개체의 메서드 호출하기

## 가비지 컬렉션(Garbage Collection)이란?

더 이상 사용(참조)되지 않는 개체의 메모리를 JVM이 자동으로 회수하는 기능

## 가비지 컬렉션 덕분에 개발자가 하지 않아도 되는 것은?

개체 메모리를 직접 해제하는 일 (C/C++의 `free`/`delete` 같은 수동 메모리 관리)

- 메모리 누수, dangling pointer 같은 실수를 방지

## 가비지 컬렉션의 대상이 되는 개체는?

더 이상 어떤 참조로도 접근할 수 없는(도달 불가능한) 개체

## 가비지 컬렉션의 단점(비용)은?

- 언제 수행될지 개발자가 정확히 제어할 수 없음
- 수행에 따른 성능 오버헤드가 발생함
