# 인터페이스의 올바른 정의

![](pocu-note/COMP2500/011-interface-vs-implementation/011-012-correct-definition-of-interface/images/correct-definition-of-interface-1.png)

이 주장을 하는 사람의 행적도 의심스러움
- 이 주장은 오랜 시간 동안 검증 결과 잘못됐다고 결과적으로 결론 났다고 이해

![](pocu-note/COMP2500/011-interface-vs-implementation/011-012-correct-definition-of-interface/images/correct-definition-of-interface-2.png)
![](pocu-note/COMP2500/011-interface-vs-implementation/011-012-correct-definition-of-interface/images/correct-definition-of-interface-3.png)

협업에서 실수를 줄이는 것이 중요함
- 특히 코딩에서 일반적으로 만드는 시간보다 실수를 고치는 시간을 많이 씀
- 모든 사람이 동의하는 규칙 + 이 규칙이 실수를 줄인다면 좋다!

![](pocu-note/COMP2500/011-interface-vs-implementation/011-012-correct-definition-of-interface/images/correct-definition-of-interface-4.png)

추상화, indirection은 모두에게 어려움
- 인간에게 그냥 어려움
- 추상화가 적을수록 실수가 적음
