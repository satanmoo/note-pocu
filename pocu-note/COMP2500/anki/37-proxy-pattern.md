# 프록시 패턴

노트 유형: **Cloze**

**Text**

프록시 패턴: 값비싼 리소스(예: 이미지 데이터)를 개체 생성 시 메모리에 올리지 않고 {{c1::로딩에 필요한 정보(이것이 프록시)}}만 저장했다가, 클라이언트가 요청할 때 로딩 — {{c2::캐시}}처럼 작동

- 문제점: "남몰래"(캡슐화) 적용되면 클라이언트가 어떤 로딩 방식을 쓰는지 알 수 없어 {{c3::병목점 찾기가 애매하고 메모리 사용량 계산이 어려움}}
