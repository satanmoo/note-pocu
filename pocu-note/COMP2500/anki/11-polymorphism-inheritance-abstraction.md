# 다형성·상속·추상화의 관계

**앞면**

추상화란 무엇이고 왜 필요한가? 다형성·상속과 어떤 관계인가?

**뒷면**

- 추상화 = 여러 대상의 ==공통 분모를 찾아 부모 클래스로 뽑아내는== 과정
- 다형성과 상속은 모두 추상화에 기반한 OO 특성
- 추상화가 필요한 이유 = 더 복잡한 문제를 해결하기 위해
- 단, 추상화(새 아이디어)는 구체적으로 코딩할 땐 없던 새 문제를 낳음 — 이를 고쳐나가는 것이 언어의 발전 (새 아이디어의 단점을 항상 생각할 것)
