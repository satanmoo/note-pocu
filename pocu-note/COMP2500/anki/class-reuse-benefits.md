# 클래스를 재사용하면 좋은 점 3가지

**앞면**

클래스를 재사용하면 좋은 점 3가지는?

**뒷면**

1. 시간 절약 — 이미 만들어진 클래스를 다시 활용하므로 처음부터 새로 작성할 필요가 없음
2. 테스트에 걸리는 시간 절약 — 이미 테스트·검증된 코드라 새로 작성한 부분만 테스트하면 됨
3. 관리 비용 절약 — 코드 중복이 줄어들어 수정할 일이 생겨도 한 곳만 고치면 됨
