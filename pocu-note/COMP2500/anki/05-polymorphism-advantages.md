# 다형성의 장점

**앞면**

다형성의 장점 3가지는? (다형성이 없을 때와 대비해서)

**뒷면**

없으면: 중재자 코드가 `if` 문으로 타입을 판단해 호출 — 개체가 스스로 책임진다는 OO 원칙과 거리가 멂

1. 타입 판단 중재자(`if` 분기) 제거 — 개체가 자신의 동작을 스스로 수행
2. 각 자료형에 맞는 코드가 한 클래스(한 파일)에 응집 — 캡슐화
3. 새로운 종류 추가 = 상속받은 클래스 파일 하나 추가로 끝 — 기존 코드·외부 패키지 수정 불필요 (→ OCP 서술 재료)
