# 리소스 로딩 방법 3가지 비교

노트 유형: **Cloze**

**Text**

리소스 로딩 방법 3가지 — ① 즉시 로딩 ② 지연 로딩+캐시 X ③ 지연 로딩+캐시 = {{c1::프록시 패턴}}. 어느 방법에도 장단점이 있음:

- 최신 데이터: ① {{c2::X (처음 실행할 때 로딩하므로 이후 원본이 바뀌면 옛 데이터)}} / ② O / ③ △ (자주 사용하는 것만 최신)
- 메모리 사용량: ① {{c3::최고}} / ② 최소 / ③ 그 중간 어딘가
- 실행 속도 병목점: ① 생성 시 / ② 사용할 때마다 / ③ {{c4::알기 힘듦}}

**Back Extra**

- 배경: 요즘 컴퓨터는 메모리가 크고 SSD로 디스크 로딩도 빠름 — 단, 인터넷 로딩은 여전히 느림 (이미지 많은 웹사이트)
