# 인터페이스는 순수 추상 클래스

노트 유형: **Cloze**

**Text**

OO에서 인터페이스는 {{c1::순수 추상 클래스}}다 — 상태(멤버 변수) 없이 동작의 시그니처(추상 메서드)만 가진 클래스

**Back Extra**

- 그래서 개체를 만들 수 없고, 동작의 시그니처만 있기에 클래스와 다른 규칙(항상 public, 다중 구현 허용)이 적용됨
- 사전적 의미는 "경계면 사이" — 사용자와 구체적인 세계("how"를 모름) 사이의 소통 경로
