# 잦은 변경 환경과 ECS

**앞면**

변경이 잦은 환경(게임 기획 협업 등)에서 깊은 상속 대신 무엇을 쓰고, 그 목적은 무엇인가?

**뒷면**

컴포넌트 **조합**(엔티티 컴포넌트 시스템, ECS)

- 목적: ==재컴파일 없이== 개체를 조립·생성하는 것
- 조합을 데이터 파일로 저장해 두면 기획자가 구성을 바꿔도 코드 수정·재컴파일이 필요 없음
- ECS는 디자인 패턴보다 큰 단위(시스템 전체)의 **아키텍처 패턴**
