# 추상 클래스·메서드의 UML 표기

**앞면**

클래스 다이어그램에서 추상 클래스와 추상 메서드는 어떻게 표기하나?

**뒷면**

*이탤릭*으로 표기 (추상 클래스 이름, 추상 메서드 모두)

- 추상 메서드를 자식이 오버라이딩한 경우엔 그 자식 다이어그램에 해당 메서드를 표시함
- (오버라이딩만 한 일반 메서드는 다이어그램에 표시 안 해도 됨)
