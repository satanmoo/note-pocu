# 인터페이스의 개념적 정의

노트 유형: **Cloze**

**Text**

인터페이스의 개념적 정의: {{c1::개체가 이해하는 명령(메시지)을 나열한 것}} — 이는 {{c2::public 추상 메서드의 집합}}과 일맥상통하며, 반드시 다형성과 함께 받아들여야 함

**Back Extra**

- 다형성을 빼고 "명령"에만 집중하면 "명령에서 커플링을 줄이는 것이 개체지향의 본질"이라는 잘못된 해석으로 빠짐 — "모든 건 인터페이스여야 한다" 주장의 뿌리
- 인터페이스라는 용어가 굉장히 다양한 의미로 사용되기 때문에 오해와 오용이 많음 — 객관적인 정의로 이해할 것
- 실무에서의 객관적 용도(함수 포인터·다중 상속 흉내 → 다형성)는 21번 카드 참고: https://pocu-site.pages.dev/pocu-note/COMP2500/anki/21-interface-practical-uses/
