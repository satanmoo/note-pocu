# 의존성과 결합도는 다른 개념

노트 유형: **Cloze**

**Text**

"의존성은 나쁘다"는 오해는 {{c1::결합도와 의존성을 같은 개념으로 착각}}한 것 — 실제로 의존성이 있는 설계는 좋은 설계인데, 그 근거는 {{c2::각 클래스의 기능이 잘 분리됨(목적 뚜렷·캡슐화·재사용성 높음)}}. 나쁜 것은 의존성이 아니라 {{c3::높은 결합도}}

**Back Extra**

- 결합도의 원론적 의미는 "상호 의존성" (시간적 결합 참고)
- A가 B에 의존 = B가 A의 필요조건
