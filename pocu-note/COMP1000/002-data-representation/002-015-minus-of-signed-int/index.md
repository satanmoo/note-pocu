# 부호있는 정수의 뺄셈

![img_73.png](pocu-note/COMP1000/002-data-representation/002-015-minus-of-signed-int/images/img_73.png)

모두 더하기로 연산 가능

## 복습 퀴즈

(Q) 다음의 두 뺄셈에 대한 질문에 답변하세요

부호없는 정수의 뺄셈
- 95(10) - 117(10) = 95 + (-117)
- **이진수로 변환:** 0101 1111(2) + 1000 1011(2) = ??
- 1111 1010(2)

부호있는 정수의 뺄셈
- -120(10) - 10(10) = -120(10) + (-10)
- **이진수로 변환:** 1000 1000(2) + 1111 0110(2) = ??
- 1 0111 1110(2)

결론적으로 그냥 비트 연산을 수행하면 됨
- 해석과 별개의 문제
