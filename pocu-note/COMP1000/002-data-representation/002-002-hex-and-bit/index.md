# 16진수와 비트

## 색상 표현과 16진수

![img_7.png](pocu-note/COMP1000/002-data-representation/002-002-hex-and-bit/images/hex-and-bit-1.png)

채도:
- 색의 강함(빛의 강함)
- 빨간색 빛이 없으면 0
- 빨간색 빛이 강하면 255

256단계 
- 2^8 = 1바이트 = 16진수 2자리

![img_8.png](pocu-note/COMP1000/002-data-representation/002-002-hex-and-bit/images/hex-and-bit-2.png)

- 그래서 색의 값을 저장할 때도 1바이트 사용
