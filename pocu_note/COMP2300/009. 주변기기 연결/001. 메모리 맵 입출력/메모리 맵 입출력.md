## 메모리 맵 입출력

![[Pasted image 20260327005134.png]]

메모리 접근에 사용하는 CPU 명령어를 주변기기 제어에 그대로 사용
- CPU 입장에서는 동일하다. 신호를 내보내는 것 뿐이다.
- 프로그래머가 CPU의 신호를 해석해 기계를 연결시킨다.

당연히 메모리 전용 *주소 공간*은 줄어든다.
