# 정수, 부호없는 정수

컴퓨터의 데이터는 내부적으로는 비트로 저장
- 이 값을 어떻게 해석(읽는 방법)하냐에 따라 값이 다르게 보일 수 있음
- 동일한 비트 패턴이라도 다른 종류의 값으로 해석할 수 있음
